## 🧩 Descripción del proyecto

**PlanIt** es una aplicación móvil desarrollada en **Android Studio** que busca optimizar la **organización personal y gestión de tareas**.  
Permite crear, editar y visualizar eventos, recordatorios y metas diarias mediante una interfaz moderna y fácil de usar.

El objetivo de este proyecto es ofrecer una herramienta ágil para estudiantes, trabajadores y cualquier persona que desee **planificar su día de forma eficiente** 📅✨.

---

## 🚀 Tecnologías utilizadas

- **Lenguaje:** Kotlin / Java  
- **IDE:** Android Studio  
- **Arquitectura:** MVVM (Model-View-ViewModel)  
- **Base de datos local:** Room / SQLite  
- **Diseño:** Material Design 3  
- **Control de versiones:** Git & GitHub  

---

## 🧠 Características principales

✅ Crear y eliminar tareas o eventos  
✅ Marcar actividades como completadas  
✅ Visualización diaria y semanal  
✅ Notificaciones y recordatorios automáticos  
✅ Diseño adaptable a distintos tamaños de pantalla  
✅ Persistencia de datos incluso sin conexión

## ⚙️ Instalación y ejecución

### 1. Clonar el repositorio

```bash
git clone https://github.com/AguantelBarcelona/PlanIt.git
```

### 2. Abrir en Android Studio
- Ve a **File → Open → Selecciona la carpeta `PlanIt`**
- Espera que Gradle configure el proyecto
- Conecta un **emulador o dispositivo físico**
- Presiona ▶️ **Run**
